# Recitation 06 中文解答与教学说明

本目录对应原 PDF 的 12 道练习，顺序与原题一致。每个文件可以独立运行；所有可执行语句都有中文解释，变量名与程序输出保留英文。教师 notebook 和这些文件使用同一份解题逻辑，学生版从教师版自动派生并按本次要求保留完整答案。

先修内容：变量、算术、条件、for 与 while 循环、字符串和列表的基本操作。本次目标是理解函数的参数与返回值、拆分任务、处理边界值，并把多个小函数组织成完整程序。

## 文件与练习目的

- `exercise-01.py`：依次预测三个原程序的运行结果；如果报错，指出程序首先到达的错误。程序 2 的定义名按笔误统一为 cal；程序 3 检查 a 的作用域及末尾未定义的 b。答案直接打印，修正程序独立放在其后。 教学目的：理解函数调用的执行顺序、全局变量、返回值，以及程序报错后不会继续向下执行。
- `exercise-02.py`：房产评估值是实际价值的 60%。每 100 美元评估值收取 72 美分的税。程序取得实际价值后，调用 computePropertyTax，计算并显示评估值和税额。原例实际价值 10000，评估值 6000，税额 43.20。 教学目的：把题目中的百分比和单位关系写成表达式，并用参数把数据传给函数。
- `exercise-03.py`：每 112 平方英尺需要 1 加仑油漆和 8 小时劳动，每小时 35 美元。取得面积与每加仑价格后，依次使用 paint_volume、labor_hours、paint_cost、labor_cost、total_cost 计算五项结果。原题没有整桶采购规则，本讲义按比例允许小数加仑。 教学目的：练习把大任务拆成职责清晰的小函数，并把前一个计算的结果传给下一个函数。
- `exercise-04.py`：编写 max_of_two_numbers，接收两个整数并返回较大者。原例 7 和 12 应返回 12。程序取得两个整数后显示结果；相等时返回共同的值。 教学目的：把条件选择封装为有返回值的函数，理解函数结果与打印结果的区别。
- `exercise-05.py`：取得五次考试分数，显示每个分数的等级以及平均分。calc_average 必须接收五个分数；determine_grade 接收一个分数。原 PDF 提到评分表却没有给出，本讲义明确暂定 0-100 分范围，A 为至少 90，B 为至少 80 且低于 90，C 为至少 70 且低于 80，D 为至少 60 且低于 70，其他为 F。 教学目的：把平均数计算与等级判断分开，练习从高到低排列条件和检查边界。
- `exercise-06.py`：实现 factorial(n) 和 combination(n, r)。组合数表示从 n 个不同物品中选出 r 个、不考虑顺序的选法数量。必须调用自己的 factorial，假设整数且 0 <= r <= n，返回整数，不用 math 模块；保留 0! = 1。原例结果分别是 10、20、1。 教学目的：理解乘积累积器的初始值、辅助函数复用以及整除与普通除法的区别。
- `exercise-07.py`：取得没有分隔符的一串数字字符，逐位求和。原例 2514 的结果是 12，因为 2 + 5 + 1 + 4 = 12。假设输入为非空的 ASCII 数字字符串。 教学目的：区分数字字符串与整数，练习逐字符转换与求和累积。
- `exercise-08.py`：把 mm/dd/yyyy 形式的日期字符串改成英文月份名、日、年，例如 03/12/2014 变成 March 12, 2014。本题假设输入日期有效，不额外加入日历合法性检查。 教学目的：练习 split、字符串转整数、列表索引和格式化输出。
- `exercise-09.py`：编写函数，返回每个句子开头字母大写后的新字符串。原例中的 hello 和 what 变成 Hello 和 What，Joe 原有的大写必须保留。这里明确约定句界为 .?!，跳过句首空白和标点，处理遇到的第一个字母，其余字符不改。 教学目的：使用布尔状态跟踪句子开头，理解字符串不可变时如何构造结果。
- `exercise-10.py`：取得一个字符串，显示出现次数最多的字符，并编写函数返回元音数量。按原题提示可用 count。明确约定频率统计区分大小写、包括空格标点；平局选最先出现者；空输入报告没有字符；元音 aeiou 的大小写都计数。 教学目的：同时完成频率最大值搜索与条件计数，理解平局规则如何由比较符号决定。
- `exercise-11.py`：在指定范围内找出所有 Armstrong 数，并报告数量、总和和平均数。k 位非负整数若等于各位数字 k 次方之和，就是 Armstrong 数；0 视为一位数。保留原例 153、1634。依次补全 count_digits、digit_power_sum、is_armstrong、report_armstrong、main；数位必须用 while 与 // 10 统计。原框架的 Call report_armstrong(). 是说明语句，要改成真正的函数调用。范围按非负且包含两端处理，空结果平均数显示 N/A。 教学目的：把取位数、取数字、谓词判断和汇总统计拆成可复用的函数，完整处理零与空结果。
- `exercise-12.py`：按原题五步检查 18 位字符串。第一步检查长度、前 17 位 ASCII 数字和末位数字或 X；第二步按 weight = (2 ** (17 - i)) % 11 加权，余数 10 转 X，其余转数字字符；第三步比较校验字符；第四步切出出生日期，并按索引 16 的奇偶返回 Male 或 Female；第五步主函数先 strip 和 upper，再先格式后校验，失败立即 return，成功后输出信息。严格使用这份练习给出的课堂校验规则，不替换为其他校验标准；这里只检查指定格式与校验和。原例 00000020000101038X 与给定公式不一致：前 17 位的加权总和为 46，余数为 2，应以 2 结尾。保留原例并报告校验失败；另标修正样例 000000200001010382。 教学目的：将验证顺序、字符处理、切片、加权累积和提前返回组织成完整的小程序。

## 原题问题与明确假设

- 第 1 题 Program 2 的 calc 按笔误改为 cal，答案为 5、Denominator was 0.、None。Program 3 首先在 a += 1 发生 UnboundLocalError，未到达最后未定义的 b。答案单元格直接打印结果或错误文字，修正代码放在下方独立单元格。
- 第 3 题未要求整桶采购，按比例允许小数加仑；第 4 题相等时返回共同的值。
- 第 5 题 PDF 中没有所说的评分表，暂定 0-100 分、A >= 90、B >= 80、C >= 70、D >= 60、否则 F。该表是教学假设。
- 第 6 题按原题保证的整数输入 0 <= r <= n 计算，返回整数，不使用 math。
- 第 7 题假设非空 ASCII 数字字符串；第 8 题只做有效日期的格式转换。
- 第 9 题以 .?! 为句界，大写其后的第一个字母，其余大小写与空白保留。
- 第 10 题频率区分大小写、包含空格标点、平局选最早字符，空串返回 None；元音 aeiou 不区分大小写。
- 第 11 题范围非负且包含两端，空结果数量与总和为零，平均数显示 N/A；原框架的英文 Call 说明替换为实际函数调用。数量、总和和两位小数均不遗漏。
- 第 12 题严格采用 PDF 给出的课堂余数校验规则；原样例末位 X 与此规则不符：前十七位加权总和 46，余数 2，原例应显示 Invalid checksum.。另列修正样例 000000200001010382。ASCII 字符范围不放宽，不加入地区码、真实身份或日历验证。校验函数在主程序中只于格式通过后调用。
