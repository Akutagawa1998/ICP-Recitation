# Recitation 08 使用说明

本套材料按原题顺序覆盖 8 道练习，学生版与教师参考版均带完整答案。

| 文件 | 用途 |
| --- | --- |
| [双语逐句授课教纲](bilingual-teaching-guide.md) | 171 组英文与中文逐句对照，含课堂提问、预期回答、演示操作和易错点，完整授课约 110 分钟。 |
| [学生英文答案 notebook](recitation-08-student.ipynb) | 纯英文题目、完整代码与已运行输出，可直接向学生展示。 |
| [教师双语参考 notebook](solution/recitation-08-teaching.ipynb) | 题目、解题思路、易错点和逐行代码注释均为英文在前、中文紧随的对照；英文可直接用于课堂讲解。 |
| [英文规范答案 notebook](recitation-08-instructor.ipynb) | 全英文的统一答案来源，用于自动生成学生版本并检查代码一致性。 |
| [中文解答目录](solution/README.md) | 各题教学目的、实现约定及 8 个可以单独运行的 Python 解答。 |

在 Jupyter 中选择 Python 3 内核，从头运行即可。第 1 题的预期异常会被捕获；第 2 题与第 8 题保留真正读取 `input()` 的函数，但演示单元格自动提供输入，因此“全部运行”不会等待输入。第 8 题演示结束后，可以在新单元格中运行 `main()`，实际键盘操作考勤系统。学生版已包含答案，展示时可先请学生预测，再显示或运行解答。

## 内容与原题约定

第 7 题仅修正 John 最后一个 `79` 和 Joe 最后一个 `92` 前面不合法的引号，所有原始成绩值不变；并列最高分保留先出现的学生，空输入返回空列表。第 8 题采用逐个输入姓名、空行结束注册、拒绝完全相同的重复姓名、按大小写匹配姓名的规则；`check_absences(student)` 的参数 `student` 表示整份名单。这些原题未明确的选择已在教纲、notebook 和中文解答中说明。

彩票号码允许重复数字与首位为零。第 3、4 题分别设置随机种子为 `8`，用于复现演示；第 8 题仅在自动演示期间固定输入与抽选顺序，正常调用函数时仍会随机抽选。

## 重新生成

在仓库根目录运行：

```bash
python3 -B notebook/recitation-08/derive_materials.py --force
```

生成脚本调用课程派生器，再按本次明确要求保留学生版英文答案；教师参考版从中文解答中的对应代码段和 `solution/teaching-translations.json` 生成，保留逐句与逐行的中英文对照。修改讲解或代码注释时也要同步对应翻译。不要独立修改学生版或教师参考版的代码。重新生成会清空这两份派生 notebook 的输出，在 Jupyter 中重新从头运行并保存即可。
