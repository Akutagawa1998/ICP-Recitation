# Recitation 08 中文备课说明

本次练习按照原题的 8 道题顺序，先学习列表和元组的差别，再将列表用于销售额、随机数、数据筛选、二维结构、学生成绩和随机考勤。需要的基础是变量、循环、条件、函数、字符串与基本输入输出。

教师参考 notebook 为 `recitation-08-teaching.ipynb`。题目说明、答案分析、任务、思路、易错点以及每行代码的注释都采用英文在前、中文紧随的对照，英文可直接读给学生听。运行逻辑取自本目录的 8 个 Python 文件，中英对照文字由 `teaching-translations.json` 提供；独立 Python 解答继续保留详细中文注释。学生版在上一级目录，按本次要求保留全英文完整答案。上一级的全英文 instructor notebook 是统一答案源，学生版从它派生，不能独立修改。

| `exercise-07.py` | 1 逐条处理学生嵌套记录，先将四个成绩变成数值，再把平均值转回字符串；2 比较平均分数值并返回对应学生的三个身份字段。 |

## 原题笔误与补充约定

- 第 7 题原 PDF 中 John 最后一个 `79` 和 Joe 最后一个 `92` 前有弯引号；程序中只把这两处改成合法的 ASCII 引号，数据不变。
- 第 7 题最高平均分并列、空列表的行为未规定：本实现并列取最先出现者，空列表返回 `[]`；`computeAverage([])` 也自然返回 `[]`。
- 第 8 题保留 `check_absences(student)` 签名；其中 `student` 参数代表整个注册列表，避免依赖全局变量。
- 第 8 题一次输入一个姓名，空行结束；姓名去掉首尾空格，重复的完全相同姓名不再次登记；查询区分大小写。
- 第 8 题抽查人数允许 `0` 到已登记人数，范围错误不修改列表；P/A 不分大小写，不合法回答重新询问；菜单中非整数字符的抽查人数会给出提示。
- 第 8 题 `main()` 退出时返回最终列表是核对状态的辅助；原题只要求退出。
- 第 3 题的每个位置均可为 0 至 9，允许重复及首位 0，因此显示时不转成一个整数。
- 第 6 题按题意接收二维数字列表，数字恰好为 1 至 9 各一次。提供尺寸、重复、对角线和越界负例。
- 第 2 至 5 题没有原题样例数值，当前课堂样例均为补充；第 3、4 题分别重设种子 8，仅为便于核对。

## 运行与修改

每个 `exercise-NN.py` 都可独立运行，不需要先执行其他题。例：在仓库根目录执行 `python notebook/recitation-08/solution/exercise-07.py`。第 2、8 题保留实际使用 `input()` 的交互函数，但脚本底部仅用标准库 `unittest.mock.patch` 临时提供预置回答，所以直接运行不会等待输入。演示会显示提示和回答；结束后恢复正常输入与随机抽样。想真正交互，请在 notebook 新单元格调用 `collect_weekly_sales()` 或 `main()`。

修改答案时同时更新英文 canonical notebook、对应的中文注释解答，以及 `teaching-translations.json` 中对应的双语题目或注释翻译，再运行上一级的 `derive_materials.py --force`，自动重新生成学生版和教师参考版。脚本会对照每个稳定代码块的 AST，发现解题逻辑不同就停止；题目译文过期或缺少英文注释翻译时也会停止，避免再次产生单语教师讲解。不应手工独立维护两个派生 notebook。生成后输出会被清空，需要从头重新运行。

默认课程派生器输出无答案练习版；本次用户明确要有答案，因此本次适配器先调用课程派生器，再放回统一源中的英文答案和简短答案解释。默认验证器应对临时目录中的普通无答案派生副本运行；最终带答案学生版和双语教师版另行做派生一致性与运行检查。
